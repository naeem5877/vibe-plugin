# Security Policy

## Supported Versions

Only the latest release of Vibe Plugin receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Vibe Plugin, please do NOT create a public GitHub issue.

Instead, please send an email to **contact@vibedownloader.me**. All security vulnerability reports will be reviewed as soon as possible.

## Scope notes

The panel runs inside Adobe Premiere Pro's CEP environment with Node.js enabled, and it downloads and runs helper programs (`yt-dlp`, QuickJS, FFmpeg) from their official GitHub releases. Reports about how those are fetched, verified or launched are especially welcome.
